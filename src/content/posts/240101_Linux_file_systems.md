# Linux File Systems

|/||
|-|-|
|`/bin`|Essential command<br />binaries<br />(윈도우의 exe파일 같은거)|
|`/boot`|System boot<br />loader files|
|`/dev`|Device files|
|`/etc`|Host-specific<br />system-wide<br />configuration files|
|`/home`|User home directory|
|`/lib`|Shared library <br />modules|
|`/media`|Media file such<br />as CD-ROM|
|`/mnt`|Temporary mounted<br />filesystems|
|`/opt`|Add-on application<br />software packages|
|`/proc`|Automatically <br />generated<br />file system|
|`/root`|System boot<br />loader files|
|`/run`|Run-time<br />program data|
|`/sbin`|System binaries|
|`/srv`|Site-specific<br />data served<br />by this system|
|`/sys`|Virtual directory<br />providing information<br />about system|
|`/tmp`|Temporary files|
|`/usr`|Read-only user files|
|`/var`|File that is expected to <br />continuously change|
